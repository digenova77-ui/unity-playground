# Abilities

No company is on this page. The source is open. The machine holds nothing. The till is closed.

This is the account of the two-face check. It is not a grant, and it does not replace any other file in this repository.

The line opens the picture. It is not identity. Nothing this check does is sold, executed, or settled.

Unity names the person and is not sold. Merit is a mirror. eFuse is the one cost. They are the same integer, or they are not a price.

A price exists only when a human report and a bot report already name the same non-negative integer. The check does not write either integer. A missing report leaves the price null. Null is not zero.

That integer is written three times: Merit on the human face, Merit on the bot face, and eFuse.

A reading that brings no pair does not name a price.

Refusals are HOLE, SAME_SOURCE, GRADE, and DIVERGE. UNKNOWN and UNSET are not a price.

This check does not read a meter. It does not set a cap. It does not settle. It does not execute.
